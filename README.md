## 🧭 About

I'm Vishnu — I like taking an idea all the way from a rough UI sketch to a running container on a server somewhere. That means writing the React frontend, wiring up the API, containerizing it, and setting up the pipeline that ships it whenever I push to `main`.

My work spans four areas that keep overlapping in practice:

- **Cloud & DevOps** — AWS EC2, Docker, Kubernetes, Jenkins, CI/CD pipelines
- **Backend Engineering** — Node.js/Express, FastAPI, JWT auth, RBAC
- **Frontend Development** — React, Tailwind CSS, data-rich dashboards
- **AI Integration** — OpenAI & Gemini APIs, computer vision (OpenCV, CNNs)

At **Punchbiz**, I put a lot of this into production — deploying FastAPI OCR/video-processing services on EC2, building MERN apps end to end, and wiring AI chatbots into real user-facing products.
